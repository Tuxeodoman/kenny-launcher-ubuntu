# Kenny Launcher для Ubuntu

Стабильная версия **1.0.13** для **Ubuntu 24.04 x86_64 и систем на её базе**.
В пакет входят Qt 6.11.1 и Java 8/17/21/25. Нужно около 3 ГБ свободного места
без учёта Minecraft.

Установка из терминала обычного пользователя:

```bash
curl -fLO https://github.com/Tuxeodoman/kenny-launcher-ubuntu/releases/download/v1.0.13-ubuntu/install.sh
bash install.sh
```

Откройте **Kenny Launcher** в меню приложений или выполните:

```bash
~/.local/bin/kenny-launcher-ubuntu
```

Установщик запросит пароль для системных зависимостей. Сам лаунчер запускайте
без sudo. Архив проверяется по SHA-256 перед установкой.

Для обновления закройте лаунчер и выполните установщик из нового релиза
**этого репозитория**. Предыдущая версия программы сохраняется рядом;
установщик не удаляет аккаунты и игровые файлы. Запускайте программу через
ярлык или команду выше: эта обёртка подключает комплектную Java и оставляет
обновление за установщиком.

При переходе с прежнего Linux-пакета 9.6.1-dev используется его профиль,
если стабильный профиль ещё не создан. Существующий стабильный профиль
или явно заданный каталог данных имеет приоритет.

Сборка 1.0.13 и состав архива проверены. Запуск этой версии на Ubuntu,
игры и работа в виртуальных машинах в этом выпуске не проверялись.

Поддержка NixOS прекращена; новые пакеты для него не выпускаются.

Состав сторонних компонентов: [THIRD_PARTY.txt](THIRD_PARTY.txt).
Версии Java и исходные контрольные суммы: [runtimes.json](runtimes.json).
